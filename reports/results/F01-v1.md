# F01 v1：请求内 prefix KV 缓存结果

状态：**REPORTED，2026-10-24**。功能正确性通过，B=4/8 的四个配置通过
性能收益门槛，B=1 的两个配置为 NO_GAIN。实现和测量均已完成。

实现提交 `61b94a0`，位于独立 serving 仓库分支 `codex/f01-prefix-kv`。上游固定为
`c70274273f489abc73832b2b98584a8483b6b203`，没有修改或复制完整模型。
默认保持 eager；Python `prefix_cache=True`、CLI `--prefix-cache` 启用缓存。

## 实现

level 0 的一次 prefix forward 同时产出 level 0 code 和每个 block 的
prefix K/V。K 保存于 QK norm、RoPE 之后；后续 levels 只投影 target，
联合访问 prefix 和当前 level 的 keys。prefix PAD 继续屏蔽，target
位置每个 level 从零开始，临时 target K/V 不写回持久缓存。

缓存属于请求状态；A/B 交接克隆缓存并清除旧状态引用。完成、取消、
执行异常释放缓存，scheduler 终态记录解除 state 引用。旧状态和外来
状态不能恢复执行。缓存模式限定 FP32 MHA 普通 residual block，拒绝
parallel block、NormFormer、LayerScale、ReZero、GQA 等未验证配置。

### 测量方法与解释

各 worker 独立加载模型，固定 FP32/TF32 off/no-grad、采样与输入顺序，
预热至少 10 批、最多 50 批，直到相邻两个五批中位数差异不超过 5%。
实际预热为 10–12 批；模型加载、输入准备和模型指纹阶段为 4.67–5.82 秒，
单独记录，不含 Python 进程导入时间；GPU 预算计入整个子进程时间。
每个 E2E 窗口 1024 样本，随后独立执行 16 批 instrumented profile，
两次测量共用模型加载、但不共用计时或迭代。正式 E2E 期间不安装 hooks。
这样保留完整五窗口矩阵，同时减少重复加载占用 GPU 预算。

E2E 边界为 CPU pretokenized prefix 到 CPU final IDs，包括 cache prefill、
交接复制和 scheduler 请求清理；不包括模型加载、文本解码、评分或输出
哈希。CPU call wall time 与 CUDA event span 分开记录；CUDA span 可包含
主机 enqueue 间隙，嵌套区间不相加，也不冒充 exclusive kernel time。

实际分派另以短 CPU-profiler 诊断确认，18 个三路径/配置组合均通过
profiler 开关前后 IDs 对齐。观测到
`aten::_scaled_dot_product_efficient_attention` / `aten::_efficient_attention_forward`，
未用此诊断做性能计时，也没有据此声称测到 exclusive CUDA kernel time。
逐 level、逐 phase 的五窗口中位数保存在机器可读汇总中。

缓存降低了位置数，但仍执行相同数量的 level/block 调用，并新增 K/V
拼接及交接复制。B=1 的结果说明位置数减少并不保证端到端收益；本轮
没有用独立 launch/kernel 消融证明其具体瓶颈。后续优化需单独提案。
现有 A/B 分界仍为 split=5，不能据此称为最优，也不能将单卡结果直接
推广为多 GPU 分离收益；跨 GPU 还需评估增加的 KV 传输成本。

## 复现

使用既有 venv，设置 `PYTHONPATH=src;.`（Windows）以及
`NCM_ROOT=<固定上游目录>`。CPU 测试：

```text
python -m unittest discover -s tests -p "test_*.py" -v
```

GPU 实验设置 `HF_HUB_OFFLINE=1`、`TRANSFORMERS_OFFLINE=1`，禁止新下载。
以下命令从独立 serving 仓库根目录执行；路径对应本工作区的既有资源：

```text
python scripts/gpu_budget.py --ledger reports/raw/F01-v1/gpu-budget.json -- scripts/validate_prefix_kv.py --ncm-root ../../upstream/ncm --checkpoint-dir ../f00/artifacts/wmt14 --tokenizer-dir ../f00/artifacts/qwen3-0.6b-tokenizer --data-dir ../f00/data/wmt14 --historical-dir ../f00/reports/raw/F00-v1/run-20261023 --output reports/raw/F01-v1/quality-01.json

python benchmarks/run_prefix_matrix.py --ledger reports/raw/F01-v1/gpu-budget.json --ncm-root ../../upstream/ncm --checkpoint-dir ../f00/artifacts/wmt14 --tokenizer-dir ../f00/artifacts/qwen3-0.6b-tokenizer --data-dir ../f00/data/wmt14 --quality reports/raw/F01-v1/quality-01.json --output-dir reports/raw/F01-v1/matrix-01

python scripts/gpu_budget.py --ledger reports/raw/F01-v1/gpu-budget.json -- scripts/inspect_sdpa.py --ncm-root ../../upstream/ncm --checkpoint-dir ../f00/artifacts/wmt14 --tokenizer-dir ../f00/artifacts/qwen3-0.6b-tokenizer --data-dir ../f00/data/wmt14 --output reports/raw/F01-v1/sdpa-dispatch.json

python scripts/summarize_prefix_kv.py --raw-dir reports/raw/F01-v1 --output reports/results/F01-v1-summary.json
```

入口拒绝覆盖已有结果。重复实验必须使用新的输出路径，并继续使用同一
累计预算账本；预算不够时需另行批准，不能删账本重置。
